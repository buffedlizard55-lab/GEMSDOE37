## Acquisition and workspace irregularities

1. **No authenticated competition rasters:** the official data tab redirected to login; user-supplied Dropbox mirrors remain unauthenticated and were not downloaded into this workspace.
2. **Direct mirror transfer failed earlier:** `curl` to Dropbox/official participant pages had TLS errors. Do not retry the same direct-download command unchanged. `gh` and public-page fetch worked.
3. **Dependencies/tests:** the environment initially lacked NumPy, SciPy, rasterio, numba, and pytest. These were installed in an ignored local `.venv`; the synthetic suite passed 37 tests on 2026-10-05. The workflow exists but has not run in GitHub Actions. Independent parity against the organizer scorer and the full real-template/portal output path remain unestablished.
4. **No result artifact:** no competition-data manifest, full spatial holdout report, current holdout-best registration, generated candidate TIFF, portal receipt, or verified improvement exists in this checkout.
5. **Historical baseline leakage:** H33 B=2 removal used the full known-fault raster. A static H33 output in a spatial holdout would include label-informed pruning from held-out regions, so it is not used as an independent fold comparator. Its reported pixel count is a fixed budget only.
6. **Score sites and access policy:** user/team-owned sibling pages are linked for manual source review; no automated monitoring of DrivenData is retained. The official leaderboard link is authoritative for a later permitted one-time user check.
