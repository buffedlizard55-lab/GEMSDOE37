Access-date and refresh policy

The source audit above was reviewed on 2026-10-05 UTC. Official rules, participant access, and leaderboard rows may change. A scheduled public-board parser runs every six hours once enabled on the repository's default branch; changed JSON is proposed as a pull request for review, so the published GitHub Pages snapshot updates only after the change is accepted and deployed. The repository must allow its Actions token to create pull requests for that last step; otherwise the job cannot publish a review request. Failed parses preserve the last snapshot and are not labeled live.

No source change is treated as verified until its actual file metadata, hash, license, grid and provenance have been checked. Read the detailed research register for acquisition outcomes and open irregularities.
