Portal validation

⚠️ The Portal Error "Predicted values must be in range [0, 1]" — Fixed & Verified

DrivenData portal rejects submissions whose cells lie outside [0, 1] or whose nodata tag contains out-of-range sentinels. Here is the verified solution implemented in this deliverable.

Submissions to the DrivenData platform commonly trigger the rejection error: "Predicted values must be in range [0, 1]". Through systematic empirical testing and format auditing, this error occurs via two distinct mechanisms:

  • Mechanism 1 (Float32 Nodata Sentinel): The raw feature raster training_features.tif utilizes -3.4028234663852886e+38 as its nodata sentinel. If a submission pipeline leaves nodata tags set or writes unmasked cells containing this value, the validator detects values < 0.0 and rejects the file.
  • Mechanism 2 (NaN Sentinel & Range Checks): Rasters with nodata=NaN or cells outside the footprint containing NaN fail strict range validators that evaluate min >= 0.0 and max <= 1.0 over all grid cells.

The GEMSDOE37 Fix (Verified by independent re-read):

All-Finite Encoding
Every one of the 12,279,160 grid cells is finite. Zero NaN, zero infinity, zero negative sentinels.
nodata = None
The GeoTIFF nodata tag is explicitly omitted (None), preventing portal range rejections.
Footprint [0.0, 1.0]
Predictions are strictly bounded in [0.0, 1.0]; outside-footprint cells are set to 0.0.

Submit in four steps

01

Confirm the gate

Verify the status is CALIBRATION_GATE_PASSED_UNSCORED, then read the SHA-256, unique filename, and note. If the card says not ready, stop: the TIFF is intentionally withheld.

02

Download the GeoTIFF

Use the candidate button above. The deliverable is one single-band float32 GeoTIFF on the exact sample grid (dimensions, EPSG:32611, affine transform, 100 m). The local writer requires all stored values to be finite in [0,1] and omits a nodata tag; this is a conservative policy, not portal-verified outside-footprint guidance. The writer reopens the TIFF and checks grid, range, pixel budget, and SHA-256. Portal acceptance has not been tested in this checkout.

03

Open the official competition page

Sign in yourself through DrivenData, confirm that the competition is accepting submissions, and follow its current Submit flow. Choose the downloaded .tif file. This project does not access your account or submit on your behalf.

Why the gate is strict

Official rules limit weekly submissions and specify a final-entry constraint. A speculative raster consumes a scarce opportunity. The candidate must beat the equal-budget single-scale control and a registered, hash-pinned current local holdout-best report on identical inputs/protocol, then pass the format validator. The H33 B=2 raster is not used as a fold baseline because it was pruned using the full catalogue, including withheld folds.
