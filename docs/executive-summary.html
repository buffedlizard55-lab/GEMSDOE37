Upload checklist

Submit in four steps

01

Confirm the gate

Verify the status is HOLDOUT_GATE_PASSED_UNSCORED, then read the SHA-256, unique filename, and note. If the card says not ready, stop: the TIFF is intentionally withheld.

02

Download the GeoTIFF

Use the candidate button above. The deliverable is one single-band float32 GeoTIFF on the official 100 m EPSG:32611 sample grid. The script reopens the saved file and checks the grid, band count, data type, nodata tag, finiteness, value range [0,1], positive-pixel budget, and SHA-256.

03

Open the official competition page

Sign in yourself through DrivenData, confirm that the competition is accepting submissions, and follow its current Submit flow. Choose the downloaded .tif file. This project does not access your account or submit on your behalf.

Open DOE GEMS competition ↗

04

Use the unique ID and note; verify the receipt

Paste the generated note in the optional submission-note field. The note begins with a unique GEMSDOE37 ID and the downloaded filename is also unique. The competition instructions available to this project do not establish a separate “submission name” field; if the live form presents one, use the same ID there. After upload, confirm the file and record the organizer-issued score and submission time.

Never infer a score from this page. The catalogue pseudo-holdout is an imperfect public-label proxy. It does not verify the organizer’s private evaluation; only the competition’s own receipt/leaderboard is an organizer score.

Why the gate is strict

Official rules limit weekly submissions and specify a final entry constraint. A speculative raster consumes a scarce opportunity. The candidate must beat both a pinned historical reference and an equal-budget single-scale control across four spatially guarded catalogue folds before output is enabled.
