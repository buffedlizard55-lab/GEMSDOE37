Check, parse, propose

A scheduled GitHub Actions job fetches the unauthenticated official HTML every six hours. A parser rejects missing/malformed score rows and preserves the prior JSON snapshot on errors. Changed data is pushed only to the fixed Arena session branch and proposed as a review PR; it does not silently rewrite the published site.

Interpret cautiously

A public score is not hidden validation

The competition leaderboard may reflect the public evaluation labels. It does not prove performance on private labels, establish which TIFF a participant used, or certify a user-reported historical file-score pairing. GEMSDOE37 has no organizer score until a participant submits through the official portal.
