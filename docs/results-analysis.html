What the metric supports

Some thinning can help

With alpha=0.2, beta=0.8 and a triangular 300 m kernel, predictions close to unmatched truth can earn credit; predictions unsupported by truth add false-positive mass. Removing redundant low-credit predictions can improve a particular proxy if useful coverage remains. That is a plausible mechanism for the reported sparse-thinning result—not a measured explanation of an organizer score.

What the official mask says

No 200 m scoring buffer

DrivenData staff say only exact provided known-fault pixels are masked. Nearby pixels are scored normally, and new/corrected/splayed truth can occur within 300 m of known traces. H33's B=2 deletion is not required by the rules and could remove pixels that otherwise receive new-fault credit.

What is needed to exceed the current board

There is no defensible leap from an owner proxy to a future public score. First obtain the participant data through an authorized route, build an exact-mask pooled spatial holdout, register and compare a current local best at a matched budget, then verify the generated TIFF against the example grid and `[0,1]` rules. Persistence is not geology

H0 persistence records connected-component births/deaths in a scalar response. The current implementation matches component maxima across smoothing scales and scores a small peak neighborhood; it does not prove an elongated fault line or geological identity. Its `epsilon` is a sensitivity assumption, and cross-scale peak matching is heuristic. See the precise method limits →
